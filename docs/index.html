Features

One job, done properly.

ScreenTextGrab lives in your menu bar and does a single thing: turn pixels into text you can paste.

Global rebindable hotkey

Start a capture from any app with ⇧⌘2, or record your own shortcut in Settings. An optional second hotkey scans the whole main display.

On-device text recognition

Uses Apple's Vision framework with Accurate or Fast modes, automatic language detection or a language list you choose. If the first pass finds nothing, it retries on the image rotated 90 degrees.

Clean output you control

Results are ordered top to bottom, left to right. Optionally join lines to remove line breaks and trim extra whitespace.

QR codes and barcodes

Turn on code reading and the payload of any QR code or barcode in your selection is copied to the clipboard.

Recent captures in the menu

The last 20 captures are kept in memory only and can be re-copied from the menu. Quit the app and they are gone.

Private by design

No accounts, servers or network calls, and no images written to disk. The app excludes its own windows from the capture.

Install

Up and running in a minute.

ScreenTextGrab is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download ScreenTextGrab-macOS.zip and unzip it.
  2. Move ScreenTextGrab.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/ScreenTextGrab.app
  4. On your first capture, grant Screen Recording in System Settings → Privacy Security, then quit and reopen the app.

FAQ

Questions, answered.

Is ScreenTextGrab really free and open source?

Yes. It is released under the MIT license, with no ads, accounts or paid tier. The full source is on GitHub, and if it saves you time you can optionally support development through the Support / Donate button.

What permissions does it need?

Screen Recording is required, because macOS only lets apps read screen pixels with it. Notifications are optional. It does not ask for Accessibility or Microphone access, since the global hotkey uses the Carbon hot key API.

Where is my data stored?

Only your settings are saved, in macOS UserDefaults. Captured images are processed in memory and released right after recognition, and the Recent Captures list is never written to disk.

Why isn't the app notarized?

Notarization requires a paid Apple Developer account, and this is a free project. Right-click the app and choose Open once to approve it, or build it yourself from source with Xcode and XcodeGen.

Was this written by AI?

Yes. ScreenTextGrab was generated by Claude Code from a written spec as a clean-room reimplementation, with no code or assets from any commercial app. The full source is on GitHub under MIT, so you can read every line before you run it. It has had less human review than a hand-written app, so bug reports are welcome.
